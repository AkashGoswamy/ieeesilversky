# Demo script (3–5 minutes)

1. Open Overview: explain the study period, 41 collars, and why these are historical daily centroids.
2. Open Movement & signals: show a collar track and the raw-to-filtered speed/visitation signal stack. Point out the lagged baseline and persistent candidate flags.
3. Open Data quality: show gaps and explain why absent collar-days are unknown rather than zero visits.
4. Open Agentic monitoring: run the local deterministic policy and inspect its evidence and tool trace. If a Groq key is available, run the optional agent; otherwise show the deterministic path.
5. Open Experiments: set a seed, run the synthetic benchmark, compare recall and false-alert burden, and export trial rows.
6. Close with the caveat: injected events are not observed wildlife events, and centroid shifts do not prove water shortage.
